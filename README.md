# CampusCompanion AI 🎓

### Your goals, opportunities, and next steps — all in one place.

CampusCompanion AI is a student-support dashboard designed to help students organize their studies, discover education-support portals, track interesting opportunities, and prepare for their careers.

Built with React and Vite, the project brings student planning and practical guidance together in one accessible interface.

## ✨ Features

### 🤖 Student Guidance Assistant

Get structured, rule-based guidance for:

* Scholarship discovery and eligibility research
* Study planning and revision routines
* Internship and career preparation
* Beginner-friendly coding project ideas

**Transparency:** The current assistant uses predefined, rule-based responses. It does not connect to a live generative AI model or retrieve live scholarship listings.

### 🎓 Scholarship Discovery

* Explore education-support and scholarship portals.
* Search opportunities by keywords.
* Filter listings by category.
* Save and unsave opportunities.
* Retain saved opportunities using browser local storage.
* Open the linked official portals for further research.

Scholarship availability, application deadlines, and personal eligibility are not verified automatically. Always confirm current requirements with the official provider.

### 📚 Study Planning

Organize study tasks, track completion, and build a manageable study routine.

### 💼 Career Preparation

Explore practical suggestions for building projects, improving GitHub repositories, preparing resumes, and developing programming fundamentals.

### 🎨 Student-Focused Interface

* Dark, modern dashboard design
* Responsive scholarship cards
* Interactive navigation
* Searchable opportunity listings
* Persistent saved-opportunity state

## 🚀 Run Locally

### Prerequisites

Install Node.js and npm before starting.

### Installation

Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd campuscompanion-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🧭 How to Use

1. Open CampusCompanion AI.
2. Visit the AI Assistant and choose a student-support topic.
3. Explore scholarship portals using search and category filters.
4. Save opportunities you want to investigate.
5. Visit the official provider websites to verify requirements.
6. Use the study-planning and career-guidance features to organize your next steps.

## 🔒 Privacy and Limitations

* Saved scholarship IDs are stored in the browser's local storage.
* The current assistant provides predefined guidance rather than live generative AI.
* Scholarship listings are discovery links, not verified announcements of currently open applications.
* Eligibility guidance does not guarantee qualification or selection.
* Do not enter sensitive personal information into a prototype.
